# Справочник настроек оркестратора (`.env`)

Всё, что читает **оркестратор**. Файл `.env` лежит в каталоге репозитория
(создаётся из `.env.example` при установке); после правки — перезапуск:
`systemctl --user restart claude-orchestrator`.

`claude-box` этот файл не читает: он настраивается флагами и несколькими
переменными окружения — [`BOX.md`](BOX.md#переменные-окружения). Как
пользоваться самим оркестратором — [`ORCHESTRATOR.md`](ORCHESTRATOR.md).

## Минимум для старта

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота от @BotFather. **Обязателен**, если в `ADAPTERS` есть `telegram`: без него оркестратор не стартует |
| `ALLOWED_USER_IDS` | пусто | Белый список Telegram ID через запятую. **Пустой список = бот игнорирует все сообщения** (в логе будет предупреждение). Кто в списке — тот и отвечает на запросы разрешений |
| `TELEGRAM_CHAT_ID` | автопривязка | ID группы с топиками. Можно не задавать: бот запомнит группу после `/chat_id` |

## Интерфейсы

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `ADAPTERS` | `telegram` | Какие интерфейсы поднять: `telegram`, `web` или оба через запятую. Пустое или неизвестное значение — отказ на старте |
| `WEB_HOST` | `127.0.0.1` | Адрес веб-интерфейса. Наружу — только за reverse-proxy с TLS |
| `WEB_PORT` | `8180` | Порт веб-интерфейса |
| `WEB_TOKEN` | автогенерация | Токен доступа к вебу. Не задан — генерируется при старте, URL с токеном печатается в лог (и выдаётся командой `/orchestrator_web`) |
| `BOT_LANG` | `ru` | Язык сообщений: `ru` или `en` |

## Сессии и Claude Code

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `SESSIONS_DIR` | `~/claude-orchestrator-sessions` | Где живут сессии: их папки, приватные `$HOME`, состояние, история. Меняешь путь на работающей установке — переноси каталог целиком, иначе сессии «пропадут» |
| `MAX_INSTANCES` | `5` | Сколько сессий может быть ЗАПУЩЕНО одновременно. Остановленные слот не занимают: процесса нет — ресурсов нет. Проверяется и при `/new`, и при возобновлении остановленной |
| `CONTEXT_WINDOW` | `200000` | Контекстное окно модели для процента заполнения в `/stats`. Claude — 200k; если прокси даёт модели с бо́льшим окном (`glm-5.2`, `deepseek` — 1M), поставь сюда реальный размер, иначе процент будет занижать запас |
| `MIN_FREE_RAM_MB` | `1024` | Сколько МБ памяти обязано остаться машине после старта сессии. Оркестратор смотрит `MemAvailable` и цену сессии (под `agent-vm` — `AGENT_VM_MEMORY_GIB`, иначе оценка процесса claude) и отказывает заранее, вместо того чтобы отдать выбор жертвы OOM-killer'у. `0` — не проверять |
| `IDLE_TIMEOUT_H` | `6` | Через сколько часов простоя сессия останавливается сама (запись сохраняется). `0` — никогда |
| `CLAUDE_BIN` | `claude` | Путь к бинарю Claude Code, если он не в `PATH` |
| `CLAUDE_CONFIG_DIR` | не задан → `~/.claude` | Профиль Claude Code (токены, скиллы, транскрипты). Задай, если держишь для оркестратора отдельный профиль. Под `SANDBOX=agent-vm` игнорируется: claude живёт в microVM со своим профилем |
| `CLAUDE_PROFILE` | — | Профиль Claude Code по умолчанию для новых сессий: отдельная учётка со своими токенами, скиллами и транскриптами. Каталоги общие с `claude-box` (`${CLAUDE_BOX_HOME:-~/.local/share/claude-box}/profiles/<имя>`), профиль создаётся сам при первом запуске. Сессия переопределяет своим `/new … --profile имя`; `--profile ""` — явно без профиля. Под `SANDBOX=agent-vm` профили не работают (гость держит учётку у себя) |
| `CLAUDE_ENV_<ИМЯ>` | — | Проброс переменной в процесс claude: `CLAUDE_ENV_ANTHROPIC_BASE_URL=…` даст процессу `ANTHROPIC_BASE_URL=…`. Так подключают свой прокси или бэкенд |
| `DEFAULT_MODEL` | — | Модель новых сессий (`opus`, `sonnet`, `haiku`, `fable` или точное имя). `/model` перекрывает для конкретной сессии |
| `DEFAULT_EFFORT` | — | Уровень усилий по умолчанию: `low`, `medium`, `high`, `xhigh`, `max` |
| `PERMISSION_MODE` | `auto` | Режим разрешений Claude Code: `auto`, `bypass`, `acceptEdits`, `manual`, `dontAsk`, `plan`, `default`. Всё, кроме `bypass`, шлёт запросы кнопками в чат |
| `INCOMING_DIR` | `incoming` | Куда складывать присланные файлы. Относительный путь — внутри папки сессии; абсолютный — общий каталог |
| `LOG_MAX_MB` | `10` | Ротация `claude.log` сессии. `0` — не ротировать |

## Изоляция

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `SANDBOX` | `bwrap` | Движок изоляции **по умолчанию**: `bwrap` (песочница), `agent-vm` (microVM, экспериментально), `off` (без изоляции). Отдельной сессии задаётся флагом `--box` у `/new` |
| `SANDBOX_EXTRA_RW` | — | Дополнительные каталоги, доступные сессии на запись; несколько — через `:`. Широкий путь (дом, корень) фактически разворачивает песочницу — в лог уйдёт предупреждение |
| `SANDBOX_DBUS` | `true` | Проброс **всего** system D-Bus в песочницу: нужен для mDNS и `.local`-хостов (`avahi-browse`, DNS-SD). `false` — запретить |
| `SANDBOX_X11` | `false` | Проброс X/Wayland. По умолчанию `DISPLAY`/`XAUTHORITY`/`WAYLAND_DISPLAY` вырезаются, чтобы процесс не дёрнул GUI хоста (askpass-диалоги, скриншоты, перехват ввода). `true` — оставить, если модели правда нужен X |
| `SANDBOX_BWRAP_DOCKER` | `false` | Дать сессии `docker`/`compose` в песочнице. У каждой сессии свой прокси над `docker.sock`: bind разрешён только внутрь папки проекта этой сессии, снос системы и доступ к соседям режется. Работает только при `bwrap`; при другой изоляции — предупреждение в логе |

## Кошелёк секретов

Подробности — [`WALLET.md`](WALLET.md).

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `SANDBOX_BWRAP_WALLET` | `true` при `SANDBOX=bwrap` | Включить кошелёк. Настройка сама объявляет модуль — `MODULES` трогать не нужно. Вне `bwrap` игнорируется с предупреждением: там кошелёк не работает |
| `WALLET_SECRETS_FILE` | `~/.config/claude-orchestrator/secrets.toml` | Файл секретов и политики (права `0600`, вне видимости песочницы). Нет файла — создастся с безопасным дефолтом |
| `WALLET_GUARD` | `1` | Встроенный запрет заведомо опасного (печать токена, RCE через флаги git) поверх политики. `0` — выключить (менее безопасно) |
| `WALLET_POLICY_EDIT` | `1` | Разрешить правку политики из чата (`/wallet`). `0` — только просмотр |
| `AUTOMODE_CLASSIFY_ALL_SHELL` | `1` | Судья `auto`-режима проверяет **все** bash-команды, а не только «на вид рискованные». `0` — меньше вопросов, слабее защита секретов |

## Внутренние адреса и порты

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `ORCH_HOST` / `ORCH_PORT` | `127.0.0.1` / `18080` | Внутренний HTTP ядра: туда ходят channel-серверы сессий и хуки |
| `ORCH_TOKEN` | автогенерация | Секрет внутреннего API. Не задан — генерируется при старте (в логе предупреждение); зафиксируй, чтобы он не менялся при каждом рестарте |
| `CHANNEL_PORT_START` / `CHANNEL_PORT_END` | авто | Пул портов для channel-серверов сессий |
| `ORCH_SYSTEMD_UNIT` | автоопределение | Имя systemd-юнита для `/orchestrator_restart`, если оно не определилось само |

## Внешний вид и поведение бота

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `SHOW_TOOL_CALLS` | `true` | Показывать вызовы инструментов в статус-бабле |
| `DELETE_BUBBLE` | `true` | Удалять бабл после ответа. `false` — оставлять журналом |
| `SHOW_COMMAND_MENU` | `true` | Регистрировать меню «/» в Telegram |

## microVM (`SANDBOX=agent-vm`)

Экспериментальный режим: сессии в микровиртуалках через наш форк
[aadegtyarev/agent-vm](https://github.com/aadegtyarev/agent-vm) (форк
[wirenboard/agent-vm](https://github.com/wirenboard/agent-vm)), нужен KVM.
Установка — [`BOX.md`](BOX.md#установка-microvm).
Ресурсы, образ и egress задаются переменными `AGENT_VM_*` — они общие с
`claude-box`, описаны в [`BOX.md`](BOX.md#переменные-окружения). Ограничения
режима — [`agent-vm-integration.md`](agent-vm-integration.md).

## Рецепты

**Только браузер, без Telegram**

```ini
ADAPTERS=web
WEB_PORT=8180
```

**Без песочницы** (машина без bubblewrap или без user namespaces)

```ini
SANDBOX=off
```

Кошелёк секретов при этом не работает — модель видит креды хоста напрямую.

**Свой профиль Claude Code для оркестратора**

```ini
CLAUDE_CONFIG_DIR=/home/user/.claude-orchestrator-profile
```

**Свой бэкенд/прокси моделей**

```ini
CLAUDE_ENV_ANTHROPIC_BASE_URL=http://127.0.0.1:8787
```

**Docker внутри сессий**

```ini
SANDBOX=bwrap
SANDBOX_BWRAP_DOCKER=true
```

**Пожёстче с разрешениями** (спрашивать чаще)

```ini
PERMISSION_MODE=manual
AUTOMODE_CLASSIFY_ALL_SHELL=1
```

**Побыстрее, без вопросов** (только для доверенных задач)

```ini
PERMISSION_MODE=bypass
```
